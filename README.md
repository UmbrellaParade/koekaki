# こえかき (Koekaki)

**話すだけで、整った文章に。**

「えーと」も、言い直しも、詰まったところも気にせず話してください。
AI がフィラーを取り除き、言い直しを整理し、そのまま使える文章にして返します。

👉 **[アプリを開く](https://umbrellaparade.github.io/koekaki/)**
（PC・スマホ両対応 / インストール不要 / 月額0円）

---

## これは何か

Typeless や Wispr Flow のような AI 音声入力ツールを、**月額課金なし**で使えるようにしたものです。
サーバーを持たない構成なので運用費がかからず、あなた自身の AI の API キーで、使った分だけ支払う形になります。

### できること

| | |
|---|---|
| 🎙️ **話すだけ** | ボタンを押して話し、もう一度押して停止。それだけ |
| ✨ **勝手に整う** | 「えー」「あの」などのフィラー、言い直し、繰り返しを自動で除去 |
| 🎯 **用途別に整形** | 標準 / メール / チャット / 箇条書き / 記事 / 議事録 / 丁寧に / カジュアル / 英訳 / 和訳 / AIプロンプト |
| 🛠️ **自分のモードを作れる** | 「note の下書き用」など、独自の整形ルールを登録できる |
| 📖 **ユーザー辞書** | 人名・作品名・専門用語を登録して誤変換を防ぐ |
| ✍️ **文体を覚える** | 自分の文章サンプルを渡すと、語尾や漢字の使い方をその文体に寄せる |
| 📱 **PC もスマホも** | PWA なのでホーム画面に追加すればアプリのように起動する |
| 🕘 **履歴** | 端末内に保存・検索・再利用。音声そのものは保存しない |
| 🌗 **ダーク／ライト** | 端末の設定に自動追従 |

### 使い方

1. アプリを開く
2. 初回だけ [Google AI Studio](https://aistudio.google.com/apikey) で API キーを取得して貼り付ける
3. マイクボタンを押して話す → もう一度押して停止
4. 整った文章が出るので「コピー」して好きな場所に貼り付ける

PC ではマイクボタンの代わりに **Space キー長押し**でも録音できます。

## 料金について

こえかき自体は無料です。月額課金もありません。AI の利用料だけが実費でかかります。

### まず「APIキーなし・完全無料」で使えます

設定を **文字起こし = ブラウザ内蔵 / 整形 = 簡易（無料）** にすると、
API キーも通信先も不要になり、音声が端末の外に出ません。費用は完全にゼロです。

ただし簡易整形でできるのは、明らかなフィラーの削除・言い詰まりの繰り返しをまとめる・
言い直しの整理・句点の補完まで。「メール調に直す」「箇条書きに構造化する」といった
判断は AI にしかできません。まず試して、物足りなければキーを入れる形で構いません。

### AI を使う場合

**Gemini の無料枠は Flash 系で1日1,500リクエスト**です。こえかきは1回の録音で1リクエストしか
使わないため、通常の使い方では無料枠を出ません。

超えた場合の目安（Gemini 2.5 Flash / 音声入力 $1.00・出力 $2.50 per 1M tokens、1分あたり約0.6円）:

| 使い方 | 月額の目安 |
|---|---|
| 1日10分 話す | 約 170 円 |
| 1日30分 話す | 約 500 円 |
| 1日1時間 話す | 約 1,000 円 |
| （比較）Typeless Pro | 約 4,650 円（月払い） |

| エンジン | 目安 | 備考 |
|---|---|---|
| ブラウザ内蔵 + 簡易整形 | **完全に 0 円** | キー不要。音声が端末外に出ない。Chrome / Edge 系のみ |
| **Gemini 2.5 Flash**（既定） | 無料枠内なら 0 円 | 1日1,500回まで無料。超過後も1分 約0.6円 |
| Gemini 2.5 Flash-Lite | さらに安価 | 音声入力 $0.50/1M。精度は Flash より控えめ |
| OpenAI (gpt-4o-mini-transcribe + gpt-4.1-mini) | 1分あたり $0.003 前後 | 無料枠なし。ノイズの多い環境に強い |
| Claude (整形のみ) | 従量課金 | 音声非対応のため、文字起こしは別エンジンと組み合わせる |

アプリ内には、リクエストごとの**概算コスト**が表示されます。

> **無料枠を使う場合の注意**
> Gemini API の無料枠は、送信したデータが Google のサービス改善に利用される規約になっています
> （有料枠は利用されません）。業務内容を扱う場合は
> [利用規約](https://ai.google.dev/gemini-api/terms)を確認してください。
> キーなし構成（ブラウザ内蔵 + 簡易整形）なら、そもそも音声が端末外に出ません。

## プライバシー

- **中継サーバーがありません。** 音声とテキストは、あなたのブラウザから各 AI 社の API へ直接送られます。開発者がその内容を受け取ることはありません。
- **API キーは端末内のみ**に保存されます（ブラウザの localStorage）。
- **音声データは保存しません。** 変換が終わった時点で破棄され、端末にも残りません。
- **履歴は端末内の IndexedDB のみ。** 設定でオフにできますし、いつでも全削除できます。

## 開発

### 必要なもの

- Node.js 22 以上

### セットアップ

```bash
npm install
npm run dev
```

開発サーバーは `http://localhost:5173/koekaki/` で立ち上がります（`base` が `/koekaki/` のため、末尾のパスが必要です）。

### ビルド

```bash
npm run build
npm run build:desktop
```

`build` はGitHub Pages向けPWA、`build:desktop` はElectron本体と専用rendererを作ります。
デスクトップ版を起動する場合は `npm run desktop` を使います。

### テスト

ルールベース整形の回帰テスト（「正当な日本語を壊していないか」の検査）:

```bash
npm test
```

Windows のデスクトップ版で使う右 Alt フックの自己テスト:

```bash
npm run test:hotkey
```

この自己テストは `SendInput` で右 Alt の押下・キーリピート・解放を再現し、
低レベルキーボードフックが1回のトグルとして検出できることを確認します。

Electron からフックを起動して受信できることまで確認する場合:

```bash
npm run test:electron-hotkey
```

安全な専用URL、sandboxed preload、非表示controllerまでまとめて確認する場合:

```bash
npm run test:electron-desktop
```

貼り付け経路を、実際のアプリへキー入力せずに自己テストする場合:

```bash
npm run test:paste
```

この自己テストは `SendInput` の `INPUT` 構造、Ctrl+V の4イベント列、
対象ウィンドウと修飾キーの判定を検査します。実際のアプリへ Ctrl+V は送りません。

デスクトップ版は、録音開始時の前面トップレベルウィンドウの
`HWND` / `PID` / `TID` を保持します。整形完了時にも同じ対象が前面にあり、
Ctrl / Shift / Alt / Win が押されていない場合だけ Ctrl+V を送ります。

対象が変わった場合、修飾キーが押されている場合、クリップボードの競合を検出した場合、
または `SendInput` が失敗した場合は自動貼り付けしません。
対象不一致や送信失敗では、可能な限り整形文をクリップボードに残します。
別のコピー操作を検出した場合は、ユーザーが新しくコピーした内容を優先します。

元のクリップボードの復元は best effort です。Unicode / ANSI / OEMテキスト、
テキストのロケール情報、HTML、RTF、ファイル一覧の安全に扱える形式だけを対象とし、
画像を含む未対応形式や大きすぎるデータが含まれる場合は復元せず、貼り付けた文章を残します。
同じトップレベルウィンドウ内で別の入力欄へ移動したことは検出できません。

実マイクからAI整形を経て実アプリへ貼り付ける通し動作は、まだ実機未確認です。

デスクトップ版のAPIキーはWeb版の `localStorage` と共有せず、Windowsの暗号化保存を使います。
ソース、環境変数、IPCの状態通知には保存しません。

このPCのApplication ControlがElectron付属のZIP展開モジュールを拒否する場合は、
次を一度実行します。公式配布ZIPのSHA-256を照合し、Windows標準機能で展開します。

```bash
npm run install:electron-binary
```

独自ドメインのルートに配置する場合は、`base` を変えてビルドします。

```bash
BASE_PATH=/ npm run build
```

### アイコンの再生成

```bash
powershell -ExecutionPolicy Bypass -File scripts/make-icons.ps1
```

### 構成

```
src/
├── lib/
│   ├── recorder.ts          MediaRecorder + 音量計測 + 無音検出
│   ├── audio.ts             webm/mp4 → 16kHz モノラル WAV 変換
│   ├── prompts.ts           整形プロンプトと組み込みモード定義（品質の核）
│   ├── rulePolish.ts        APIキー不要のルールベース整形
│   ├── pipeline.ts          文字起こし → 整形 の制御
│   ├── providers/           Gemini / OpenAI / Anthropic / Web Speech API
│   ├── storage.ts           設定（localStorage）
│   ├── db.ts                履歴（IndexedDB）
│   └── cost.ts              概算コスト計算（料金改定時はここだけ直す）
└── components/              UI
```

### 設計上のポイント

- **Gemini を文字起こしと整形の両方に使う場合、1回のリクエストで完結する**（`geminiCombined`）。2回叩くより速く安い。
- **Gemini は WebM を公式サポートしていない**ため、音声は必ず 16kHz モノラル WAV に変換してから送っている。OpenAI は WebM をそのまま受けるので変換しない。
- 整形プロンプトには「要約しない・情報を足さない・前置きを付けない」を明示している。ここを緩めると途端に使い物にならなくなる。

### デプロイ

`main` に push すると GitHub Actions が自動でビルドし、GitHub Pages に公開します。
