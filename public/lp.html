よくある質問

話した音声はどこかに保存されますか？

いいえ。音声は変換が終わった時点で破棄され、端末にも残りません。履歴として保存されるのはテキストのみで、それも端末内だけです。履歴の保存自体を切ることもできます。

API キーは安全ですか？

キーはお使いのブラウザ内にだけ保存され、こえかき側には送信されません（そもそも中継サーバーが存在しません）。共用のパソコンでは、使い終わったあとに設定画面からキーを消してください。

iPhone や Android でも使えますか？

使えます。ブラウザで開いて「ホーム画面に追加」すると、アプリのように起動します。整った文章はワンタップでコピーでき、他のアプリにそのまま貼り付けられます。

他のアプリに直接入力できますか？

現在はできません。こえかきはブラウザアプリのため、他のアプリのカーソル位置に文字を送り込むことは技術的にできない仕組みになっています。「コピーして貼り付ける」形での利用になります。デスクトップ常駐版（グローバルホットキー対応）を開発予定です。

日本語以外も使えますか？

英語・中国語・韓国語などにも対応しています。設定から話す言語を選ぶか、自動判定に設定してください。英訳・和訳モードを使えば、話しながら翻訳することもできます。

オフラインで使えますか？

画面自体はオフラインでも開きますが、音声の変換には通信が必要です。AI 各社の API へ音声を送って処理しているためです。
